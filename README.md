# Expense Tracker API

A complete _Expense Tracker API_ built with **FastAPI**, **SQLAlchemy**, and **JWT authentication**. This project provides a robust foundation for building secure and scalable backend services.

## Key Features

- **Project Setup:** Efficient environment configuration and dependency management .
- **Data Validation:** Built-in validation using _Pydantic_ models.
- **Database Integration:** Persistent data storage using _SQLAlchemy ORM_ and _SQLite_ .
- **Modular Routing:** Clean project structure for maintainable, scalable code .
- **Secure Auth:** Industry-standard **JWT authentication** for protected API endpoints .
- **Documentation:** Automatically generated _Swagger UI_ for seamless testing .
